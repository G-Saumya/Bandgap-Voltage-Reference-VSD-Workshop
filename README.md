## 📖 About

This repository documents my learning from the **Bandgap Voltage Reference workshop conducted by VSD**. It covers the theory behind bandgap references, along with the hands-on lab experiments performed each day of the workshop.

## 📂 Repository Structure

The documentation is organised **day-wise**. Each `DayX` folder contains a `README.md` with the concepts covered and the lab experiments performed that day.
